# حرب القوى العظمى (Modern Travian)

لعبة استراتيجية حربية حديثة أونلاين في المتصفح. مباراة من ساعة إلى ٣ ساعات، من ٢ إلى ٨ لاعبين (مع بوتات اختيارية).

## التشغيل على جهازك
```
npm install
npm start
```
ثم افتح http://localhost:3000

## النشر أونلاين (Render مجاناً)
ارفع المجلد على GitHub، ثم في Render أنشئ Web Service:
- Build Command: `npm install`
- Start Command: `npm start`

## المميزات
- ١٠ دول بمميزات وعيوب، خريطة العالم الحقيقية أو خريطة عشوائية
- غذاء وسكان، تجارة، دبلوماسية ومهام مع البوتات، تحالفات
- أزمات دولية (وساطة/دعم/تصعيد)، مجلس الأمن والفيتو، أحداث اقتصادية
- أبحاث، صواريخ، أقمار صناعية، قادة عسكريون، سلاح نهائي

## الملفات
- `game.js` قواعد اللعبة والمحاكاة (الدول، الوحدات، القتال، النقاط).
- `bot.js` ذكاء البوتات.
- `world.js` بيانات خريطة العالم (العواصم، المضائق، المواقع، السواحل).
- `server.js` السيرفر (HTTP + WebSocket) والغرف.
- `public/` واجهة المتصفح.
